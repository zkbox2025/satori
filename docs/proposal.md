企画書
以下「satori」というアプリを開発したい。
①このアプリで何を解決できるか：
人生においての大切な気づきは例えメモしていても振り返ることが少ない。その理由として、振り返りたいときに整理できていないからだと考える。古い書籍にも見られるように賢者は人生においての気づきを整理して書物として次世代に残した。人生における気づきを記録・整理でき作品として残せるようなアプリを開発することで、未来の自分自身のため、さらには他の人の人生のためになるのではないかと考え開発に至った。

②このアプリでできること：
誰もが自分の気づきを記録し整理し後で見返せる。自分の気づきをAIで作品化できる（詩的にできたりする）。人（AI）に自分の気づきを聞いてもらってフィードバックがもらえる。他人の人生の気づきや気づきを基にした作品を読むことができる。
完成後にオプションとして、作品の出版や購入等が可能にしたい（余裕があればでO K）

④主要データ
※作品のジャンル表示は、紐づく元記事 Work.genre を使用する。GeneratedContent 自体には genre カラムを持たない。
※User.id は supabase Auth の auth.users.id と同一の値を使う。
※Feedback は Work ごとに1件のみ保持する。再生成時は新規作成ではなく更新する。

model User {
  id                    String                 @id
  createdAt             DateTime               @default(now())
  updatedAt             DateTime               @updatedAt
  name                  String?
  email                 String                 @unique
  avatarUrl             String?
  bio                   String?
  works                 Work[]
  feedback              Feedback[]
  generatedContents     GeneratedContent[]
  workLikes             WorkLike[]
  generatedContentLikes GeneratedContentLike[]
  aiRateLimitEvents AiRateLimitEvent[] 
}

model Work {
  id         String     @id @default(uuid())
  createdAt  DateTime   @default(now())
  updatedAt  DateTime   @updatedAt
  title      String
  content    String
  genre      String // slug形式 (例: "mental-health")
  visibility Visibility @default(PRIVATE)
  status     Status     @default(DRAFT)
  userId     String
  user       User       @relation(fields: [userId], references: [id], onDelete: Cascade)

  feedback          Feedback?
  generatedContents GeneratedContent[]
  likes             WorkLike[]

  @@index([userId])
  @@index([userId, status, visibility])
  @@index([status, visibility, createdAt])
}

model Feedback {
  id        String   @id @default(uuid())
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  content String @db.Text // SUCCESS時に本文。ERROR時は空文字でもOK運用

  workId String
  userId String
  work   Work   @relation(fields: [workId], references: [id], onDelete: Cascade)
  user       User       @relation(fields: [userId], references: [id], onDelete: Cascade)

  prompt            String?   @db.Text
  inputSnapshot     Json?
  resultJson        Json?
  modelName         String?
  status            AiStatus @default(PENDING)
  errorMessage      String?  @db.Text
  tokensInput       Int?
  tokensOutput      Int?
  costUsdMicro      Int?
  promptVersion     Int      @default(1)
  providerRequestId String?

  @@unique([workId])
  @@index([workId])
  @@index([status, updatedAt])
}

model GeneratedContent {
  id        String   @id @default(uuid())
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  title         String
  generatedText String @db.Text

  visibility Visibility   @default(PRIVATE)
  style      ContentStyle

  workId String
  userId String
  work   Work   @relation(fields: [workId], references: [id], onDelete: Cascade)
  user       User       @relation(fields: [userId], references: [id], onDelete: Cascade)

  likes GeneratedContentLike[]

  prompt            String?   @db.Text
  inputSnapshot     Json?
  resultJson        Json?
  modelName         String?
  status            AiStatus @default(PENDING)
  errorMessage      String?  @db.Text
  tokensInput       Int?
  tokensOutput      Int?
  costUsdMicro      Int?
  promptVersion     Int      @default(1)
  providerRequestId String?

  @@index([workId])
  @@index([userId])
  @@index([userId, visibility])
  @@index([visibility, createdAt])
  @@index([status, createdAt])
}

model WorkLike {
  id        String   @id @default(uuid())
  createdAt DateTime @default(now())

  userId String
  user   User   @relation(fields: [userId], references: [id], onDelete: Cascade)

  workId String
  work   Work   @relation(fields: [workId], references: [id], onDelete: Cascade)

  @@unique([userId, workId])
  @@index([workId])
  @@index([userId])
}

model GeneratedContentLike {
  id        String   @id @default(uuid())
  createdAt DateTime @default(now())

  userId String
  user   User   @relation(fields: [userId], references: [id], onDelete: Cascade)

  generatedContentId String
  generatedContent   GeneratedContent @relation(fields: [generatedContentId], references: [id], onDelete: Cascade)

  @@unique([userId, generatedContentId])
  @@index([generatedContentId])
  @@index([userId])
}

model AiRateLimitEvent {
  id        String   @id @default(cuid())
  userId    String
  action    String
  createdAt DateTime @default(now())

  user User @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@index([userId, action, createdAt])
}

enum ContentStyle {
  POEM
}

enum Visibility {
  PUBLIC
  PRIVATE
}

enum Status {
  DRAFT
  PUBLISHED
}

enum AiStatus {
  PENDING
  SUCCESS
  ERROR
}





⑤画面の流れ
※記事作成画面（/works/new）、記事編集ページ（/works/[id]/edit）、ログインページ（/login）以外の全ページに以下の表示を一番上に入れる：「satori」というアプリ名を一番上（ヘッダー）の一番左につける（押すとメインページ(/explore)に飛ぶ）。同じ行の右端にアイコン画像（押したらスライドメニューが出てくる。一番上の右端にはアイコン（押すと画像がアップする）と名前（押すとマイページ（/users/[userId]）に飛ぶ）があり、その右端には×があり押したらスライドメニュー（モーダル）が消え前のページに戻る。その下に、マイページボタン（マイページ（/users/[userId]）に飛べる。）と「設定」ボタン（設定ページ（/settings）へ飛ぶ)が四角に囲まれて横二列に並んでいる。その下に記事/作品という見出しがあり、その下に、「自分の記事」（記事一覧ページ（/works）に飛べる）と「下書き」（下書き一覧ページ（works/drafts）に飛べる）と「自分の作品」（作品一覧ページ(/generated)に飛べる）が縦に並んでいる。その下に「いいね」という見出しがあり、その下に、「記事」(いいね記事一覧ページ（/likes/works）に飛べる)や「作品」(いいね作品一覧ページ（/likes/generated）が縦に並んでいる。一番下にログアウトボタンがあり、押すとログアウトした状態でメインページ(/explore)に飛ぶ。このようにスライドメニュー（モーダル）はナビゲーションの役割がある）アイコン画像の右横には記事⚪︎件（公開/非公開を含み、下書きを含まない記事）、作品⚪︎件（公開/非公開を含む作品）という表示が出る。その表示の右横に鉛筆マークをつけて押すと文章入力画面（/works/new）に飛ぶ。
※自分専用ページは本人以外は見られない。公開ページは全員閲覧可。非公開記事/作品は本人のみ閲覧可。AIフィードバックは本人のみ閲覧可。編集削除は本人のみ可能。
※PDF出力は自分の記事（フィードバックは除く）と作品で可能
※記事一覧のカード情報について：記事タイトル、作成日または更新日、いいね数、ジャンル、非公開ラベル（記事一覧ページ（/works）のみ追加）、アイコンと名前（explore記事一覧ページ（/explore/works）といいね記事一覧ページ（/likes/works）のみ追加）がカードを見るとわかる
※作品一覧のカード情報について：作品タイトル、作成日、いいね数、ジャンル、非公開ラベル（作品一覧ページ（/generated）と記事からの作品集（/users/[userId]/works/[workId]/generated）のみ追加）、style、アイコンと名前（explore作品一覧ページ（/explore/generated）、いいね作品一覧ページ（/likes/generated）、記事からの作品集（/users/[userId]/works/[workId]/generated）のみ追加）がカードを見るとわかる
※下書き一覧のカード情報について：記事タイトル、最終更新日、ジャンル、がカードを見るとわかる


※【明文化】
Work
* status = DRAFT（下書き）
    * /works/drafts に出る
    * 他人から見えない
* status = PUBLISHED（保存ずみ） かつ visibility = PRIVATE（自分のみ）
    * /works に出る
    * 自分だけ見える
* status = PUBLISHED（保存ずみ） かつ visibility = PUBLIC（全体に公開）
    * /works に出る
    * /users/[id] や /explore にも出る
GeneratedContent
* visibility = PRIVATE（自分のみ）
    * 自分だけ見える
* visibility = PUBLIC（全体に公開）
    * 他人も見える

※記事に紐づく複数の生成作品を表示するために、記事からの作品集（/users/[userId]/works/[workId]/generated）を作成する。このページでは、対象記事を元に生成・保存された作品を一覧表示する。他人がアクセスした場合は公開作品のみ表示し、本人がアクセスした場合は非公開作品も表示する（非公開ラベル付き）。各作品を押すと、既存の作品詳細ページ/users/[userId]/generated/[generatedId]へ遷移する。
※記事カード本体を押す⇨ユーザー記事詳細ページ（/users/[userId]/works/[workId]）
※作品カード本体を押す⇨記事に紐づいた作品が一件の場合は、ユーザー作品詳細ページ（/users/[userId]/generated/[generatedId]）。二件以上ある場合は、記事からの作品集（/users/[userId]/works/[workId]/generated）
※「戻る」ボタンを押すと前のページに戻る。
※Work.title は作成時に必須入力。GeneratedContent.title は作品保存時にAIが初期値を入れる。その後、本人のみ編集可能。
※未ログイン状態で自分専用ページ(/works, /generated, /works/drafts, /likes/works, /likes/generated, /settings, /works/new, /works/[id]/edit)へアクセスした場合は /login へリダイレクトする。
※/users/[userId] は公開プロフィールページとして扱う。自分がアクセスした場合も同一URLで公開プロフィール表示を行う。管理操作は自分専用ページで行う。

⑤-1 メインページ(/explore)（公開ページ）
一番上の行：一番上には検索の箱があり、そこに入力するとヒットした全ての記事や作品が出る（プルダウン：記事（デフォルト）であれば記事の中からヒットして、プルダウン：作品であれば作品の中からヒットする）。検索結果がない場合は、「検索結果がありません」という表示になる。
検索箱の下の左端にプルダウン（記事（デフォルト）/作品）があり、選択できる。デフォルトはプルダウン：記事。プルダウンの選択により、URLパラメータで/exploreの後ろに?tab=works / ?tab=generatedをつけてユーザーがサクサク切り替えられるようにする。表示される記事や作品を押すと、それぞれの詳細ページ（ユーザー記事詳細ページ（/users/[userId]/works/[workId]）やユーザー作品詳細ページ（/users/[userId]/generated/[generatedId]）へ飛ぶ））へ飛ぶ。

プルダウンの下には、最新記事/作品と人気記事/作品とジャンル別記事/作品の項目が縦に並んでいて（プルダウンで記事を選択したら記事カードが表示され、作品を選択したら作品カードが表示される）それぞれ最新5件が並んでいる（5件ごとにもっと見るボタンが表示され押すと次の5件が表示される）。最新記事/作品については、記事/作品カードが最新順に5件並んでおり、最新記事/作品の表記を押すとexplore記事一覧ページ（/explore/works）もしくはexplore作品一覧ページ（/explore/generated）に飛ぶ。人気記事/作品については、記事/作品カードがいいね順に5件並んでいる。ジャンル別記事/作品はジャンル名ごとに分けられており、最新順で記事/作品カードが5件ずつ並んでいる。最新記事/作品と人気記事/作品とジャンル別記事/作品の項目全て5件ずつ並んでおり5件ごとにもっと見るボタンが出てもっと見るボタンを押すと次の5件が表示される（その繰り返し）。記事や作品がない場合は、「まだ記事/作品がありません」という表示になる。


⑤-2記事作成画面（/works/new）（自分専用ページ）
一番上の行：右端に「下書き保存」と「公開に進む」が横に２列で並んでいて（下にスクロールしてもずっと一番上の行にいるように設定する）、「下書き保存」を押すと下書き一覧ページ（/works/drafts）に飛ぶ。「公開に進む」を押すと公開設定画面（公開するのボタンと非公開で保存のボタンがあり選べるようになる（モーダル））を挟んで自分のユーザー記事詳細ページ（/users/[userId]/works/[workId]）に飛ぶ。左端には×ボタンがあり編集途中でそれを押すと下書きを保存しましたという表示が出て閉じるボタンを押すと下書き一覧ページ（/works/drafts）に行く。編集なしで左端の×ボタンを押すとそのまま記事一覧ページ（/works）に行く。
「下書き保存」と「公開に進む」の行の下：タイトル入力スペースがありその下にジャンル選択プルダウンがあり、ジャンルを選択する
ジャンル選択プルダウンの下：本文入力のスペースがある（一旦は普通に文字が打てる機能でOK。完成後に画像アップロードや大きめ文字小さめ文字、色文字の選択実装に挑戦したい）。本文入力スペースの下に戻るボタンがある。

⑤-3記事一覧ページ（/works）（自分専用ページ）
一番上の行の左端に「自分専用記事」という表示があり、その表示のすぐ下には検索の箱があり、そこに入力するとヒットした自分の記事カードが出る。検索結果がない場合は「検索結果がありません」という表示になる。検索箱の右横には戻るボタンがあり、ボタンを押すと前のページに戻る。検索箱の下にはメインプルダウンがあり、「最新順（デフォルト）」「古い順」「いいね順」「更新順」「ジャンル別」に選択でき、メインプルダウンの横にはプルダウンメニューがあり、「すべて」「公開のみ」「非公開のみ」が選択できる。メインプルダウンとプルダウンメニューの選択によりメインプルダウンの下にある自分が作成した記事カードが並べ替えられる（非公開の記事に関しては「非公開」という表記を出す）。並べ替えられた記事カードが15件以上ある場合は、もっと見るボタンが出て、それを押すと次の15件が表示される（15件ごとにもっと見るボタンが表示される）。記事カードの右端に･･･がありそれを押すと「編集」と「削除」というボタンがプルダウンで出てきて「編集」を押すと記事編集ページ（/works/[id]/edit）に行き、「削除」を押すと「削除します。よろしいですか？」という表記（モーダル）が出て下に「キャンセル」と「削除する」のボタンがあり「削除する」を押すと削除後の記事一覧ページ（/works）へ行く。「キャンセル」を押すとそのままの記事一覧ページ（/works）に戻る。記事がない場合は、「まだ記事がありません」という表示になる。並べられている記事を押すと、ユーザー記事詳細ページ（/users/[userId]/works/[workId]）へ飛ぶ。


⑤-4作品一覧ページ（/generated）（自分専用ページ）

⑤-14設定ページ（/settings）（自分専用ページ）
一番上の行の左端に「設定」と書いてあり、アイコン画像、名前、自己紹介という項目が縦に並んでいる。各項目の下に現在登録しているアイコン画像、名前、自己紹介が書いてあり、その右横に変更ボタンがある。アイコンの変更ボタンを押すとプルダウンで画像アップロードという表示が出て、それを押すとプルダウンで「写真ライブラリ」と「写真を撮る」という二つの表示が出る（他のところをタップするとプルダウン表示は消える）。「写真ライブラリ」を押すと自身の写真ライブラリに飛び画像を選択しアイコンとしてアップロードすることができる。「写真を撮る」を押すとカメラに飛びカメラで撮った写真をアイコンとしてアップロードすることができる。
名前の変更ボタンを押すと、以下のモーダルが出てくる。名前という表示の下に箱の中に登録されている名前が書いてあり、名前を書き換えることができるところがあり、その下に「キャンセル」と「保存」ボタンがある。保存ボタンを押すと保存され、名前変更後の設定ページ（/settings）に飛び、キャンセルを押すと変更なしの設定ページ（/settings）へ飛ぶ。
自己紹介の変更ボタンを押すと、以下のモーダルが出てくる。自己紹介という表示の下に箱の中に登路されている自己紹介文が書いてあり、自己紹介を書き換えることができるところがあり、その下に「キャンセル」と「保存」ボタンがある。保存ボタンを押すと保存され、自己紹介変更後の設定ページ（/settings）に飛び、キャンセルを押すと変更なしの設定ページ（/settings）へ飛ぶ。ページの一番下に「戻る」ボタンがあり、押したら前のページに戻る


⑤-15記事からの作品集（/users/[userId]/works/[workId]/generated）（公開ページ）
一番上の左端にアイコン画像と名前、最新作成日が書いてある。その下に「作品集」と書いてありその表示の下に最新順で記事に基づいた作品カードが並べられてある。作品カードをクリックするとユーザー作品詳細ページ（/users/[userId]/generated/[generatedId]）へ飛ぶ（15件ごとにもっとみるボタンが表示される）。その下には「作品のもとになった記事」という表示の下に作品の元になった記事カードが表示されている。ページの一番下には「戻る」ボタンがあり、押すと前のページへ戻る。本人閲覧時のみ非公開作品も非公開ラベルつきで追加で表示される。

⑤-16ログインページ（/login）
一番上の左端に「satori」というアプリ名がありその下の中央にログイン/アカウント作成という見出しがある。その下にプルダウンがある（「ログイン」（デフォルト）と「アカウント作成」を選べる）。ログインプルダウンを選択すると、メールアドレスとパスワードの入力画面が出てきて、その下には「ログイン」ボタンと「パスワードを忘れた方はこちら」ボタンがある。アカウント作成プルダウンを選択すると名前、メールアドレス、パスワード、パスワード確認の入力項目があり、その下に「アカウント作成」ボタンがある。そのほかにエラーメッセージの表示を実装する。ログイン成功後、アカウント作成成功後はメインページ(/explore)に飛ぶ。なお、未ログイン状態で自分専用ページ(/works, /generated, /works/drafts, /likes/works, /likes/generated, /settings, /works/new, /works/[id]/edit)へアクセスした場合は /login へリダイレクトする。未ログインの時は、ヘッダーの「satori」の右端にログインボタンを設け、ボタンを押すとログインページ（/login）へ行けるようにする。
